Software

Stata and R programs related to my research.

Stata commands

Some programs associated with my research are distributed through SSC or journal repositories.

mfelogit

Average marginal and treatment effects in fixed-effects binary logit models. With Laurent Davezies, Christophe Gaillac, and Louise Laage.

ssc install mfelogit

fuzzydid

Difference-in-differences procedures for fuzzy treatment designs. With Clément de Chaisemartin and Yannick Guyonvarch.

ssc install fuzzydid

testex

Testing an exclusion restriction in the control-function setting; developed by Yuya Sasaki.

ssc install testex

segregsmall

Segregation indices for settings with small units. With Lucas Girard and Roland Rathelot.

net install st0631

eqregsel

Estimation of a sample-selection model without standard excluded instruments. With Arnaud Maurel, Xiaoyun Qiu, and Yichong Zhang.

net install st0598

For other programs, including two-way clustering inference, see the original software page.
